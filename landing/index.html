A API de PIX feita para quem desenvolve com IA

Conecte a PushinPay ao Claude, Cursor ou qualquer agente e crie cobranças PIX, consulte saldo e transações — em linguagem natural, sem escrever integração.

$ npx -y @pushinpay/mcp-server
Ver recursos →

Comece em minutos

Adicione o servidor MCP ao seu cliente de IA com o token da sua conta. Pronto — o agente já opera a PushinPay.

Gere seu token

No painel PushinPay, crie um token de API.

Cole a configuração

Adicione o bloco ao Claude Desktop, Claude Code ou Cursor.

Converse

“Crie uma cobrança de R$ 50 na PushinPay.” O agente faz o resto.

// claude_desktop_config.json / mcp.json
{
  "mcpServers": {
    "pushinpay": {
      "command": "npx",
      "args": ["-y", "@pushinpay/mcp-server"],
      "env": {
        "PUSHINPAY_TOKEN": "seu_token",
        "PUSHINPAY_ENV": "sandbox"
      }
    }
  }
}
